# 独立レビュー
調査とHTML作成者とは別担当が、提出された固定commit SHAを対象に確認する。
- 事故を全て扱い、項目の復旧を金庫/アカウントの復旧へ広げていない。
- 期限、対象プラン、権限は公式原文を実取得しURLと対応している。根拠なしの期間・無制限保証がない。
- 削除/完全削除、device/app消去/cloud削除、個人/家族/組織、履歴/同期/backup/解除救済の違いが明確。
- kinkoの現状が基準sourceと一致し、暗号化で可用性を保証したりmaster password紛失だけで一律救済不能と断定していない。
- HTMLは平易で核心が先に読める。外部assets/JSなし、viewport、日時、出典の位置、長いURLや表の幅を確認。
- source/credential操作等の範囲外変更がない。
REVIEW_RESULTS.mdに対象SHA、担当分離、取得した公式source、finding/重大度/修正結果、ブラウザ未検証を記す。修正後SHAを再確認し古いPASSを引き継がない。手元AIが最後に全内容と表示を検収する。
